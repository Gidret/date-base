# Графическое приложение «Телефонная книга» (project_py_db)

Настольное графическое приложение (GUI) на Python, представляющее собой цифровую телефонную книгу. Программа позволяет удобно хранить, искать и редактировать контактные данные (ФИО, номера телефонов, email) с помощью интуитивно понятного интерфейса с графическими кнопками.

## 🛠 Технологический стек

* **Язык разработки:** Python 3.x
* **Интерфейс (GUI):** Tkinter (стандартная библиотека Python) / Pillow (для работы с иконками)
* **База данных:** SQLite3 (встроенная легковесная СУБД)

## 💻 Функционал телефонной книги

Управление контактами полностью визуализировано с помощью графических иконок на панели инструментов:
* ➕ **Добавить контакт (`add.png`):** открытие формы для внесения нового контакта (Имя, Телефон, Email, Дополнительно) в базу данных.
* 📝 **Редактировать (`update.png`):** изменение данных существующего абонента (например, при смене номера телефона).
* ❌ **Удалить (`delete.png`):** быстрое удаление выбранного контакта или группы контактов из книги.
* 🔍 **Поиск (`search.png`):** мгновенная фильтрация списка абонентов по ФИО или номеру телефона.
* 🔄 **Обновить список (`refresh.png`):** сброс поискового фильтра и перезагрузка полной таблицы контактов.

## 🚀 Инструкция по локальному развертыванию

### 1. Клонирование репозитория
Склонируйте проект к себе на компьютер и перейдите в целевую директорию:
```bash
git clone https://github.com
cd date-base
```

### 2. Подготовка окружения (Рекомендуется)
Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate     # Для Windows
```

### 3. Установка внешних библиотек
Для корректного отображения `.png` иконок в интерфейсе Tkinter обычно используется библиотека **Pillow**. Установите её:
```bash
pip install Pillow
```

### 4. Запуск телефонной книги
Запустите главный исполняемый файл приложения:
```bash
python main.py
```
При первом запуске программа автоматически создаст локальный файл базы данных (например, `phonebook.db` или аналогичный в зависимости от кода) в папке проекта.

```bash
let total = 4500;
let quantity = 4;
let registered = true;

// Проверяем все условия для получения скидки 15%
if (total >= 3000 && quantity >= 3 && registered) {
    let discountedTotal = total * 0.85; // Итоговая цена со скидкой 15%
    console.log("Стоимость со скидкой:", discountedTotal);
} else {
    console.log("Стоимость без скидки:", total);
}

```
